# LUME – Virtual Study Room

**A Collaborative Digital Space for Focused Learning, Productivity, and Peer Interaction.**

LUME is a virtual study room platform designed to make studying more engaging, structured, and collaborative. It provides students with a dedicated digital environment where they can organize their learning activities, connect with other learners, track their productivity, and maintain consistent study habits.

The platform aims to recreate the atmosphere of studying together in a physical library while incorporating digital productivity tools that support independent and collaborative learning.

---

##  Key Features

###  User Authentication
- User registration and login interface.
- Personalized access to the study environment.
- Dedicated user experience for individual learners.

###  Virtual Study Rooms
- Create and join virtual study spaces.
- Study alongside other learners in a shared environment.
- Dedicated spaces to encourage collaborative learning and accountability.

###  Pomodoro Productivity Timer
- Structured study sessions using the Pomodoro technique.
- Dedicated focus and break intervals.
- Encourages time management and consistent study routines.

###  Digital Study Library
- Organized learning resources in a centralized space.
- Easy access to study materials.
- Helps students maintain an organized learning environment.

###  Leaderboard
- Productivity-based leaderboard.
- Encourages healthy competition among learners.
- Motivates users to maintain consistent study habits.

###  Focus Sounds
- Background sounds to create a distraction-free study atmosphere.
- Supports concentration during study sessions.

###  Video Interaction
- Video-based interaction to create a more connected virtual study experience.
- Encourages peer engagement and collaborative study sessions.

##  Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/21khushijoshi/LUME-.git
```

**2. Navigate to the project directory**

```bash
cd LUME-
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

##  What Makes LUME Different?

Traditional productivity applications primarily focus on individual task management. LUME takes a collaborative approach by combining virtual study spaces, productivity tracking, learning resources, and peer interaction.

Rather than simply helping students manage their time, LUME aims to create an environment that makes consistent learning more engaging and sustainable.
